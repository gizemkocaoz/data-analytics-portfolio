# Marketing Campaign Performance Analysis

## Project Overview

This project analyzes Facebook Ads and Google Ads marketing performance using SQL and visualizes the results in Looker Studio.

The analysis includes campaign performance, media source comparison, UTM campaign tracking, and monthly performance trends.

---

## Technologies

- PostgreSQL
- SQL
- Looker Studio

## SQL Analysis

The project includes:

- Daily campaign performance metrics
- CPC, CPM, CTR and ROMI calculations
- Facebook & Google Ads data merging
- Campaign and Ad Set analysis
- Top-performing campaign identification
- UTM Campaign analysis
- Monthly performance comparison using Window Functions
